# Designing the deep noise suppression comparisons

## Establish the benchmark rows before inspecting scores

| Family | What the benchmark row establishes | Source information to record |
|---|---|---|
| Direct U-Net | Supervised one-evaluation reference | Source inapplicable. Record the observed network input. |
| SGMSE+ | Score-based enhancement reference | Verify the sampling prior and its dependence on the observation from the checkpoint configuration. |
| SB-VE | Bridge reference for the path comparison | Identify the observed endpoint, perturbation and schedule. |
| ICFM | Path with depth-independent conditional variance | Specify the source for this checkpoint, including any perturbation of the noisy endpoint. |
| FM | Path whose conditional variance grows to unit variance at the source endpoint | Record the endpoint mean and covariance and how the sampler draws its initial state. |

Use the chapter convention of clean speech at u=0 and the source at u=1. For its Gaussian FM path, zero mean and identity covariance at u=1 give the standard-normal endpoint. ECHI currently writes OT-FM with depth increasing from noise to speech. Substitute one minus that depth when comparing schedules. Record the conditional path variance separately from the distribution of noisy recordings across the dataset.

For every row record the checkpoint identifier, family, source (data-derived or independent standard normal, as verified), explicit condition, path schedule, training objective, sampler and actual network evaluations. An observation-centred Gaussian is data-derived. Record the architecture and training differences relevant to any claimed ablation. Resolve SGMSE, SGMSE+ and the comment about SGMSE++ against the saved configuration or original source. A historical SGMSE score supplies no evidence for a local SGMSE+ row.

## Score the same signals

Use these columns for every performance table, including ablations: PESQ, intelligibility, SI-SDR (dB), DNSMOS P.808 and WhiSQA. Label intelligibility as ESTOI on VoiceBank–DEMAND and STOI on ECHI. Verify and name the variant for URGENT. State the PESQ bandwidth. Verify the DNSMOS output against the evaluator before including it: both OVRL and the unverified legacy DNSMOS column require P.808 rescoring.

For each metric, score the enhanced signal and designated noisy input using identical references, preprocessing and segmentation. Subtract the noisy score item by item and average those differences. Use common valid item IDs across the rows being ranked for that metric and report their count. Keep raw scores and item IDs for auditing. Display the noisy row as zero. For blind data without clean references, retain the intrusive metric columns with a dash and explain why. Keep historical values with incompatible protocols out of ranked comparisons until matching audio or per-item scores can be recovered. For uncertainty, resample paired items and identify the unit and confidence level. An utterance interval for one checkpoint describes variation over utterances.

## Comparison matrix

| Experiment | Rows, controls and evidence needed |
|---|---|
| VoiceBank full data | Score all five families on the same 824 channel-0 whole test utterances. Recover local SB-VE, original ICFM and a verified SGMSE+ checkpoint. Identify later ICFM variants separately. Group by inference budget and give fixed-time, annealed and fine-tuned DDP their own ablation. |
| Original paths | Keep SB-SV here to test path shape alongside SB-VE and ICFM. Pair objective or sampler comparisons at fixed path settings. Report both k and c when both change. Recover original outputs for P.808. |
| Evaluation budget | Sweep compatible iterative checkpoints over common NFE, with direct U-Net as a one-evaluation reference. Count network calls for each solver. Label DDP separately from one-step integration. Include P.808 and WhiSQA alongside the three intrusive metrics at each budget. Treat test-set peaks as descriptive. |
| Speaker count | Use the same speaker subsets at 1, 3, 7, 13 and 26 speakers. Inventory original ICFM, SB-VE and verified SGMSE-family checkpoints at each count. Apply one documented validation selection rule, then score that checkpoint on the common held-out test set with all five metrics. Replace the best filename PESQ and final-epoch 20-item SI-SDR summaries. Report optimiser updates; isolating the effect of speaker count requires matched updates. |
| Explicit conditioning | Pair each ablated ICFM, SB-VE or score model with its conditioned counterpart at fixed source, training protocol, sampler and NFE. Use the same 770 validation utterances for the existing comparison. Fixed-time training changes a second factor. Train a matched counterpart if the archive lacks one. |
| URGENT transfer | Carry the full-data checkpoints forward, including original ICFM and SB-VE. Identify the existing official SB-VE m5 separately from a locally trained checkpoint. If originals are archived, check the 26-speaker sweep and label any substitute by its actual training run. Keep blind and nonblind splits separate, with channel 0, identical windows and matched budgets. Record the reason for each missing family. |
| ECHI | Define a fixed noisy mono reference (default: microphone channel 0) and score it against the same target segments under the official alignment protocol. Keep all four conditioning channels and enrolment fixed. Report direct and GridNet at one evaluation and compare iterative systems at one and 16 calls per window. Document how the existing SBVE adaptation defines its source and path. To test source choice, compare a declared mono projection of the observation with a Gaussian source under matched conditioning, backbone, training budget and sampler. |

## Recover the evidence in order

1. Inventory checkpoint configurations, per-item scores and saved enhanced audio. Link each intended row to its actual run and split. Check the speaker-count archive for original-family checkpoints before scheduling training.
2. Recompute paired deltas from compatible per-item scores. Rescore saved audio for missing metrics, especially P.808 and the budget-sweep WhiSQA values. Where only checkpoints survive, regenerate outputs with the documented sampler and budget.
3. Identify comparisons that require new training, especially matched conditioning pairs and the ECHI source ablation. Report unavailable rows explicitly. ECHI held-out evaluation additionally requires the missing speaker assignments and enrolment audio; label the existing results as development results.
